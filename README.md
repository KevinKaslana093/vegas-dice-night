# 拉斯维加斯 · 骰子之夜 V7.2

中文四人桌游原型：1名玩家与3名电脑、2名玩家与2名电脑、或4名玩家同屏轮流。无远程联机、无真实金钱交易、电脑不调用语言模型。

本版补全下注前后预览、残局提示和自由毕业挑战；「霓虹下的第一局」仍由月兔带领牛仔完成24步实操，随后可独立挑战最后一桌，支持退出续玩。

[在线游玩](https://kevinkaslana093.github.io/vegas-dice-night/) · [下载离线版](https://github.com/KevinKaslana093/vegas-dice-night/releases/latest)

推送到本仓库 `main` 分支后，GitHub Actions 会先执行规则测试和文件检查，再将 `dist/` 的游戏文件发布到 GitHub Pages。托管配置、测试和工程文档不进入网页发布目录。

## 本地打开

需要 Node.js 22 或更新版本来运行检查，游戏本身直接在浏览器中运行。

```sh
npm test
npm run build
python -m http.server 4317 --directory dist
```

打开 `http://localhost:4317`。也可使用任意静态网站服务器托管 `dist/`；模块版需要通过 HTTP 打开。源码已包含角色插画、音效和粒子，无需配置 API 密钥。

## 此版玩法

- 开局四选一，单人控制所选角色；双人控制所选角色及下一位，四人全部操作。开局可选普通版或角色技能版。
- 每人每轮首次进入小游戏桌时触发骰子21点或比大小，最多获得2点桌内加成，计入排名与撞数，不增加实体骰子或奖金。特殊模式确保1–3号至少有一个小游戏桌。
- 钞票显示当前暂领者，角色在撞数或奖金归属变化时回应。

- 每轮每人8颗骰子（技能版短裤女士9颗），掷出全部剩余骰子，选一个点数，将该点数的全部骰子投入对应赌场。
- **跳过**：掷出后支付1枚筹码放弃本次行动；每轮发2枚筹码，剩余可累计，筹码不足不能跳过，不下注、不扣骰。轮到下一位，顺序再次回到自己时重新掷全部剩余骰子。只剩一人有骰子时，跳过后立即再次轮到此人。
- 每轮每座赌场固定两张钞票，按两张合计从小到大分配到1–6号，允许相同总额。采用经典54张钞票的数量与面额分布，未分奖金回收；每轮轮换先手。
- 基础结算：同数量全部出局，剩下的人按骰子数量依次各拿一张钞票。四轮后总奖金最高者胜；相同比钞票张数，再同并列获胜。
- 支持“仅1–3特殊”“六座全部特殊”和“全部经典”三种模式，默认仅1–3特殊。每轮从九种效果中无放回随机分配给特殊赌场，本轮期间固定，下轮重新抽取；并非固定号码绑定效果。

|效果池（号码每轮随机）|特殊效果|
|---|---|
|先到先得|多者优先；同数不出局，首次入桌更早者优先|
|以少胜多|同数出局；少者优先拿钞票|
|赢家通吃|同数出局；最多骰子的幸存者拿走全部钞票|
|幸运七|同数出局；离7最近者先拿，相同距离按首次入桌顺序|
|末班车|同数出局；最后一次入桌越晚，越先拿钱|
|第二名大奖|第一名拿小钞，第二名拿大钞；只有一人时大钞回收|
|骰子21点|从12点开始掷骰累加，16–18加1、19–21加2、爆点加0|
|比大小|相同算输，首胜可收手加1，连胜加2，追猜失败加0|
|三颗起步|少于3颗不参与；达到门槛后同数出局、多者先拿|

特殊玩法与筹码跳过属于此版自定义设计，不代表官方扩展。公开累计奖金以方便观察。基础机制参考 Rüdiger Dorn 设计的 Las Vegas：https://www.ravensburger.org/spielanleitungen/ecm/Spielanleitungen/26938_Vegas_EN.pdf 。

## 角色技能版

普通版与技能版均使用筹码重投。开局默认技能版，可切换普通版。

|角色|技能|
|---|---|
|短裤女士 · 初来乍到|被动，每轮9颗骰子|
|牛仔 · 正义执行|每轮一次，狙掉任意玩家手中、刚掷出或桌上一颗实体骰子；本轮失效，下轮恢复|
|老板 · 主场优势|每轮一次，至少持有1枚筹码；将全部筹码交给另一玩家，强制交换某桌实体骰子数；加成不交换|
|兔女郎 · 魅力四射|每轮一次，随机抽走另一玩家的一张已有钞票；结算后甚至最后一轮仍可使用，赢家随金额更新|

技能面板在对手回合也可打开，选择时暂停牌桌；无有效目标不消耗次数。电脑也会使用技能。筹码仅用于重投或交易，不作为最终现金奖金。

## 操作与角色

点击掷骰、选骰或赌场预览、确认放入，或跳过。每桌底部规则标签可查看详细效果。键盘：空格掷骰，1–6选择，Enter确认，S跳过，Escape暂停。

六座赌场顺时针呈圆形排列，角色在外围。四张独立角色插画：短牛仔裤女士、穿深棕非牛仔布长裤且持筹码的牛仔、加高身材的烟斗老板、保留认可造型的兔女郎。角色按不同相对高度展示，点击立绘可查看大图。图片由内置 imagegen 逐个生成，为不透明深色背景 PNG。

进度与设置仅在当前浏览器保存。V6沿用V5牌局存档，独立于V1/V2/V3/V4，避免把旧局的钞票和效果在中途改掉。

## 运行与验证

静态入口 dist/index.html，通过任意静态HTTP服务器运行，无需安装依赖。npm run build 验证静态文件与JavaScript，npm test 执行48项规则测试。tests/variant-browser.js 为Playwright CLI的run-code检查脚本。

已检查1600局种子对局（包含三种模式）、奖金与骰子守恒、全部特殊规则、筹码支付与不足时禁止跳过、只剩一人时重投、预览与实际一致、存档恢复、完整浏览器四轮流程、360/390/768/1100/1500宽度与角色加载。WebMCP只读接口为可选功能，测试浏览器未提供原生支持。

## 动画演出版
四张独立表情特写、斜切入场与技能结果镜头，自己与电脑技能都播放；短裤女士的被动每轮展示一次。立体六面骰按真实掷骰结果落定，下注有骰子飞入赌场。设置中的演出试映不修改牌局。可跳过、关闭特写、加速，支持系统减少动态效果和切出页面暂停。音效与粒子来自Kenney CC0素材，许可随静态文件提供。
演出与规则分离：先提交并保存动作，再播放镜头，跳过或刷新不会二次结算。原有V5存档继续可用。

## V7 新手引导：霓虹下的第一局
开场和牌桌菜单均可进入24步互动教学。默认扮演牛仔，月兔全程对话提示，目标操作发光，其余操作禁用；编排固定骰子、先观察再操作，通过实际下注、撞数、狙击破局、付筹码跳过、轮转、21点小游戏及真实派彩完成一轮。手动推进，不强迫倒计时；沿用可跳过的掷骰和技能演出，支持减少动态效果。

教学独立创建练习状态，所有动作复用正式规则，逐步保存可重建的章节进度，不写入正式牌局存档。退出或刷新后从入口续学，通关后可重练；返回开局页默认选中牛仔，保留继续原牌局入口。教学为固定示范关，正式局骰子和特殊效果随机。

参考《明日方舟》和《崩坏：星穹铁道》的固定示范场景、角色带领、分步开放操作这一教学方式。对话、美术和界面为本作内容，不包含上述游戏的素材。浏览器检查覆盖桌面、390与360宽度全流程、操作不被对话遮挡、退出刷新续学、重练、毕业和正式存档隔离。

## V7.1 奖金归属反馈

- 钞票显示当前暂领者，易主时翻转高亮；撞数的骰堆同时亮红，并保留划线状态。
- 短暂提示逐张展示金额与原主人、新主人，并列出各玩家暂领金额的净变化；最近一手的记录也保留在操作区下方。
- 下注、牛仔狙击、老板交换及小游戏加成共用真实规则的归属结果；同面额的两张钱分别处理。提示不改变钱包和骰子，刷新不会重新播放或重复执行操作。
- 技能结果与小游戏窗口内可直接查看影响，教学也包含相同反馈。支持收起提示、加快节奏和减少动态效果。

## V7.2 决策预览与自由毕业挑战

- 选择骰子后，预览两张钞票的归属，以及每位玩家下注前后的骰子数、暂领奖金和撞数变化。小游戏桌提示尚未计算待触发的加成，预览不修改牌局。
- 残局提示谁还能下注、各自剩余骰子，以及尚未使用的主动技能。只剩一位玩家时明确说明付筹码跳过后立即再次轮到自己。
- 完成教学后进入「最后一桌」毕业挑战，也可从开局页直接进入。玩家自由选择投注、付筹码重投或狙击，真实结算后判定是否拿到目标大奖；支持多种赢法，失败后由月兔解释并可重试。
- 毕业挑战单独保存完整进度，支持退出、刷新后继续，不覆盖正式牌局。提示按需展开，不限制玩家按指定顺序操作。
- 浏览器验证覆盖桌面、390与360宽度、成功和失败路线、付费重投、技能操作、刷新续玩及存档隔离；离线版验证完整24步教学到毕业流程。
