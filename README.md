# 拉斯维加斯 · 骰子之夜

经典基础规则的非官方中文网页版原型。原创界面，无商业美术素材，无真实金钱交易。

支持四人桌：一名玩家与三名电脑、两名同屏玩家与两名电脑，或四名同屏玩家。电脑使用本地策略，不调用语言模型。没有远程联机。

每人每轮8颗骰子；每次将一个点数的全部骰子放入相应桌；所有相同数量均被排除，再依次分配单张钞票。共四轮，奖金相同比钞票张数。使用54张原版面值分布、未分奖金回收、轮换先手。不含中立骰扩展。与实体玩法的一项区别：练习版公开累计奖金。

桌游机制设计：Rüdiger Dorn。基础规则参考 https://www.ravensburger.org/spielanleitungen/ecm/Spielanleitungen/26938_Vegas_EN.pdf 。

操作：点击掷骰，点击骰子或赌场预览，点击确认放置。键盘：空格掷骰，1–6选择，Enter确认，Escape暂停。

静态入口 dist/index.html，可通过静态HTTP服务器运行。源文件无需安装依赖，npm run build 验证静态资产，npm test 执行规则测试。保存进度与设置仅保留在当前浏览器；禁用存储时仍可游玩，但不保存。

已验证：1000局种子对局的资金与骰子守恒、同数全部排除、非法动作、最终平分、完整浏览器四轮流程、存档恢复、同屏切换、暂停，以及360/390/768/1440宽度。WebMCP为可选只读牌桌接口，当前测试浏览器不支持原生API。
