# 拉斯维加斯 · 骰子之夜 V4

中文四人桌游原型：1名玩家与3名电脑、2名玩家与2名电脑、或4名玩家同屏轮流。无远程联机、无真实金钱交易、电脑不调用语言模型。

## 此版玩法

- 开局四选一，单人控制所选角色；双人控制所选角色及下一位，四人全部操作。角色没有额外能力。
- 每人每轮首次进入小游戏桌时触发骰子21点或比大小，最多获得2点桌内加成，计入排名与撞数，不增加实体骰子或奖金。特殊模式确保1–3号至少有一个小游戏桌。
- 钞票显示当前暂领者，角色在撞数或奖金归属变化时回应。

- 每轮每人8颗骰子，掷出全部剩余骰子，选一个点数，将该点数的全部骰子投入对应赌场。
- **跳过**：掷出后可不限次免费放弃本次行动，不下注、不扣骰。轮到下一位，顺序再次回到自己时重新掷全部剩余骰子。只剩一人有骰子时，跳过后立即再次轮到此人。
- 每轮每座赌场固定两张钞票，按两张合计从小到大分配到1–6号，允许相同总额。采用经典54张钞票的数量与面额分布，未分奖金回收；每轮轮换先手。
- 基础结算：同数量全部出局，剩下的人按骰子数量依次各拿一张钞票。四轮后总奖金最高者胜；相同比钞票张数，再同并列获胜。
- 支持“仅1–3特殊”“六座全部特殊”和“全部经典”三种模式，默认仅1–3特殊。每轮从九种效果中无放回随机分配给特殊赌场，本轮期间固定，下轮重新抽取；并非固定号码绑定效果。

|效果池（号码每轮随机）|特殊效果|
|---|---|
|先到先得|多者优先；同数不出局，首次入桌更早者优先|
|以少胜多|同数出局；少者优先拿钞票|
|赢家通吃|同数出局；最多骰子的幸存者拿走全部钞票|
|幸运七|同数出局；离7最近者先拿，相同距离按首次入桌顺序|
|末班车|同数出局；最后一次入桌越晚，越先拿钱|
|第二名大奖|第一名拿小钞，第二名拿大钞；只有一人时大钞回收|
|骰子21点|从12点开始掷骰累加，16–18加1、19–21加2、爆点加0|
|比大小|相同算输，首胜可收手加1，连胜加2，追猜失败加0|
|三颗起步|少于3颗不参与；达到门槛后同数出局、多者先拿|

特殊玩法与无限跳过属于此版自定义设计，不代表官方扩展。公开累计奖金以方便观察。基础机制参考 Rüdiger Dorn 设计的 Las Vegas：https://www.ravensburger.org/spielanleitungen/ecm/Spielanleitungen/26938_Vegas_EN.pdf 。

## 操作与角色

点击掷骰、选骰或赌场预览、确认放入，或跳过。每桌底部规则标签可查看详细效果。键盘：空格掷骰，1–6选择，Enter确认，S跳过，Escape暂停。

六座赌场顺时针呈圆形排列，角色在外围。四张独立角色插画：短牛仔裤女士、穿深棕非牛仔布长裤且持筹码的牛仔、加高身材的烟斗老板、保留认可造型的兔女郎。角色按不同相对高度展示，点击立绘可查看大图。图片由内置 imagegen 逐个生成，为不透明深色背景 PNG。

进度与设置仅在当前浏览器保存。V4牌局存档独立于V1/V2/V3，避免把旧局的钞票和效果在中途改掉。

## 运行与验证

静态入口 dist/index.html，通过任意静态HTTP服务器运行，无需安装依赖。npm run build 验证静态文件与JavaScript，npm test 执行25项规则测试。tests/variant-browser.js 为Playwright CLI的run-code检查脚本。

已检查1300局种子对局（包含三种模式）、奖金与骰子守恒、全部特殊规则、连续免费跳过、只剩一人时重投、预览与实际一致、存档恢复、完整浏览器四轮流程、360/390/768/1100/1500宽度与角色加载。WebMCP只读接口为可选功能，测试浏览器未提供原生支持。
