## 玩法与运行

中文四人桌游原型：1名玩家与3名电脑、2名玩家与2名电脑、或4名玩家同屏轮流。无远程联机、无真实金钱交易、电脑不调用语言模型。

新手入口改为“三手实操”：掷骰→同点全选→下注→观察撞数→加注拿回奖金→派彩。第一课不启用技能或小游戏，每次操作后最多提示三处变化；只放大当前赌场。完成后可直接开无技能的经典基础局，或自选第二课。原24步技能、筹码与特殊桌教学改为进阶课，保留独立进度。

保留角色大厅、七人横向选角、新美术、手机底部操作、第四轮提示、同局再战与关键转折回放。

## 本地打开

需要 Node.js 22 或更新版本来运行检查，游戏本身直接在浏览器中运行。

```sh
npm test
npm run build
python -m http.server 4317 --directory dist
```

打开 `http://localhost:4317`。也可使用任意静态网站服务器托管 `dist/`；模块版需要通过 HTTP 打开。源码已包含角色插画、音效和粒子，无需配置 API 密钥。

## 当前玩法规则

新版七人技能与16种皇家模块见 [V14更新说明](RELEASE-V14.md)。通常每轮7小＋1大，短裤女士技能版9小＋1大；大骰是一颗实体，计数为2。每桌两张钞票，六桌合计金额递增；同计数先出局，余下者按排名各拿一张。四轮结束，钞票加剩余筹码（每枚1万）的总额最多者获胜，同额比较钞票张数。

皇家池采用90张钞票分布，原来的9种原创效果仍可单独选择。皇家模块每次入桌处理，轮末型按说明等待派彩；同板两面不共存，未见优先。图鉴的单桌练习只打一轮并独立保存。旧存档继续使用旧技能，不在进行中改规则。

皇家模块依据与封桌奖励轨道等数字版差异已在游戏图鉴和更新说明列出。本作保留四轮、原创角色和公开累计奖金，不声称完全复刻实体皇家版。
